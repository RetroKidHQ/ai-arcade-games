# AI Arcade Games

Retro arcade games built entirely by artificial intelligence.

Every game on this site was designed, coded, and debugged by AI — no human wrote the code. This project showcases what AI can build from scratch.

## Games

- **Space Invaders** — Defend Earth from alien invasion
- **Dig Dug** — Tunnel underground and defeat monsters
- **Pac-Man** — Clear the maze while avoiding ghosts
- **Agent 7** — Infiltrate the bunker and escape undetected
- **Galaga** — Shoot the alien swarm and destroy the flagships

## Tech

- Pure HTML/CSS/JavaScript (no frameworks)
- Original chiptune music synthesized in-browser with the Web Audio API
- Hosted on GitHub Pages
